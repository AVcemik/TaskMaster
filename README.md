# 🚀 Изучение React Native & Expo: Проект "Task Master"

📌 Данный репозиторий представляет собой процесс моего самостоятельного изучения **React Native** с использованием инструмента **Expo**. Главная цель проекта — разработка полноценного коммерческого приложения *«Task Master»* («Менеджер задач»), которое станет демонстрацией полученных навыков и компетенций.

## ✅ Цели изучения:

- Освоение основ **React Native** и лучших практик разработки мобильных приложений.
- Получение глубокого понимания экосистемы **Expo** и её преимуществ перед классической разработкой React Native.
- Разработка реального функционального продукта с удобным UX и продуманным дизайном.
- Подготовка к запуску коммерческого приложения на рынок.

## ☑️ Инструменты и технологии:

- **React Native**: Библиотека JavaScript для создания кросс-платформенных мобильных приложений.
- **Expo**: Ускоренная разработка с автоматической сборкой и доступом к готовым API устройств.
- **Redux / Context API**: Управление состоянием приложения.
- **Navigation**: Навигация внутри приложения (StackNavigator, BottomTabNavigator).
- **AsyncStorage**: Локальное хранение данных.
- **UI Kit**: Создание красивого и интуитивного дизайна интерфейса.

## 💡 Основные задачи приложения "Task Master":

- Удобный интерфейс для добавления и редактирования задач.
- Совместные задачи для нескольких пользователей.
- Категоризация задач по приоритетам и срокам исполнения.
- Напоминания и уведомления о сроках выполнения.
- Синхронизация данных через облачные сервисы.

## 🛠️ Этапы разработки:

1. Прохождение обучения с помощью ИИ по React Native Expo.
2. Прохождение базовых курсов и документации по React Native Expo.
3. Практическое освоение ключевых концептов и инструментов.
4. Разработка прототипа приложения с минимальным набором функций.
5. Добавление новых возможностей и улучшение удобства использования.
6. Полировка дизайна и подготовка к публикации в магазинах приложений.

## 🎯 Итоговый продукт:

По завершении курса изучения будет создано готовое приложение *«Task Master»*, подходящее для широкого круга пользователей, которым нужен удобный менеджер задач.
